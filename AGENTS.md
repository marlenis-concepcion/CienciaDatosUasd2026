# Índice del repositorio

Lee primero `.ia-index/PROJECT-INDEX.md` para localizar archivos y símbolos antes de explorar el repositorio. Abre después solo los archivos necesarios para la tarea; el índice no sustituye la comprobación del código.

El índice fue generado con [IA Project Indexer](https://github.com/RaffyRod/IA-Project-indexer) v1.8.0. Refleja el contenido al momento de su generación y puede quedar desactualizado.

Para actualizarlo desde la raíz del repositorio:

```sh
npx --yes --package=ia-project-indexer@1.8.0 ia-index index . --no-ai-config
git add -f .ia-index/PROJECT-INDEX.md
```

Este repositorio publica deliberadamente el índice en GitHub. No publiques el registro global del indexador ni archivos de credenciales.

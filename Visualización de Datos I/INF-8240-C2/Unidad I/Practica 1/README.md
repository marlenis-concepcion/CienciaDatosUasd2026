# Práctica 1 · Evaluación integral de la Unidad I

Caso ficticio: ComercioDigital RD.

## Entrega

- `Entrega_Visualizacion_Datos_I.pdf`: análisis de las 11 actividades y presentación de cuatro diapositivas integrada.
- `Calculos_Visualizacion_Datos_I.xlsx`: datos originales, 29 fórmulas editables, resultados de referencia y tres gráficos. Las fórmulas se recalculan al abrir en Excel o LibreOffice.
- `Presentacion_Visualizacion_Datos_I.pptx`: cuatro diapositivas editables.
- `graficos/`: cuatro visualizaciones PNG.

Fuente única: consigna de UASDVirtual facilitada por la estudiante; no se inventaron observaciones. El año de los datos no está especificado. Revisar el trabajo antes de entregarlo.

## Reproducir

Instalar Python y las bibliotecas de `requirements.txt`, y ejecutar `python generar_entrega.py` desde esta carpeta.

# Consigna-exams-2025-DIA-II-jul-2026

Entregables para el quiz de recuperación de Ciencias de Datos I, INF-8237-C2.

## Archivos principales

- `Consigna-exams-2025-DIA-II-jul-2026.docx`: documento editable ampliado con evidencia, tablas y conclusiones.
- `Consigna-exams-2025-DIA-II-jul-2026.ipynb`: cuaderno para subir y ejecutar en Google Colab.
- `generar_entrega.py`: script reproducible que vuelve a crear el DOCX, el cuaderno y las tablas CSV.

## Uso en Google Colab

1. Subir `Consigna-exams-2025-DIA-II-jul-2026.ipynb` a Google Drive.
2. Abrirlo con Google Colab.
3. Subir `oulad.zip` al entorno de Colab o montar Google Drive y ajustar la variable `DATA_PATH`.
   - En este repositorio el ZIP local está en `../Practica_04_Proyecto_Final_OULAD/data/oulad.zip`.
4. Ejecutar `Entorno de ejecución > Ejecutar todas`.
5. Compartir el enlace público del cuaderno o entregar el DOCX editable como evidencia.

## Cobertura de la consigna

- Estructura de datos y valores faltantes.
- Descriptivas: media, mediana, dispersión, desviación, varianza, rango y curtosis.
- Distribuciones, pivots/crosstabs y matriz correlacional.
- Pearson y Spearman.
- t-test, ANOVA, ANCOVA y MANOVA aproximada.
- Matriz de confusión.
- RandomForestClassifier y RandomForestRegressor.
